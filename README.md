# Приглашение на юбилей 30 лет ✨

Интерактивный лендинг-приглашение с эффектом кинематографичного параллакса, покадровой анимацией Петербурга, опросником для гостей и панелью администратора.

## 🚀 Быстрый запуск локально
```bash
npm install
npm start
```
Сервер запустится на `http://localhost:8030` (порт можно задать через переменную `PORT`).

- **Основной сайт:** `http://localhost:8030/`
- **Панель управления гостями:** `http://localhost:8030/admin`
- **PIN-код по умолчанию:** `1212`

## ⚙️ Настройки и переменные окружения (.env)
- `PORT` — порт сервера (по умолчанию `8030`)
- `ADMIN_PIN` — секретный пин-код для доступа к `/admin` (по умолчанию `1212`)
- `TELEGRAM_BOT_TOKEN` *(опционально)* — токен Telegram-бота для мгновенных уведомлений
- `TELEGRAM_CHAT_ID` *(опционально)* — ID чата или группы для получения ответов

## 🌐 Деплой на Onreza (app.onreza.ru)
1. Создайте репозиторий на GitHub и загрузите файлы проекта.
2. В панели `app.onreza.ru` нажмите **Добавить проект** (или Создать сайт) и выберите ваш GitHub-репозиторий.
3. Платформа Onreza автоматически определит проект Node.js и запустит команду `npm start`.
4. В разделе переменных окружения (Environment Variables) при желании укажите свой `ADMIN_PIN`.
